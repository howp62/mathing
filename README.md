# mathing — 수학과 나를 잇는 시간

고등학생이 **단원을 시작하기 전에 스스로** 열어서, 그 단원과 자기 관심사·진로의 연결을 직접 글로 써 보고, 다른 학생들이 쓴 연결을 이름 없이 둘러보는 웹사이트예요. 현직 고등학교 수학교사가 바이브코딩(Claude Code)으로 만들고 있어요.

학생이 수학과 자기 삶의 연결을 **스스로 써 보면** 흥미가 오르고, 자신감이 낮던 학생에게 효과가 더 크다는 연구(Hulleman & Harackiewicz, 2009)에서 출발했어요. 문제 풀이나 점수는 없어요.

## 단원 하나 (5~10분)

1. 별명과 비밀번호로 로그인
2. 지금 시작하는 단원 고르기
3. "이 단원이 나와 관련 있다고 느낀다" 점수 매기기
4. "이 단원은 어디서 나올까?" 카드 보기
5. 내 관심사에 맞는 예시 카드와 생각 열기 질문
6. 3단계로 나만의 연결 쓰기 → 저장(다른 학생에게 이름 없이 공유)
7. 같은 단원을 쓴 친구들의 연결 보기, 공감 보내기
8. 내 연결 노트에서 쓰기 전·후 변화 보기, 단원을 다 배운 뒤 다시 써 보기

## 개인정보와 보안

- 이름·학교·학번·이메일을 받지 않아요. 친구들에게는 이름 없이 보여요.
- 비밀번호는 되돌릴 수 없게 섞어서 저장하고, 5번 틀리면 잠겨요.
- 욕설과 개인정보는 저장 전에 걸러내고, 신고된 글은 숨겨요.

보안 문제를 발견하면 공개 이슈 대신 이 저장소의 **Security → Report a vulnerability**로 알려 주세요.

## 운영자 2단계 초기화

운영자 화면은 비밀번호 다음에 휴대폰 인증 앱의 6자리를 한 번 더 확인해요. 휴대폰을 바꿨다면 운영자 화면의 **기록 → 인증 앱 다시 연결**을 쓰고, 휴대폰이 없으면 예비 코드로 들어갈 수 있어요.

휴대폰과 예비 코드를 **모두** 잃었을 때만, Supabase 대시보드의 SQL Editor에서 아래를 실행한 뒤 다시 로그인하면 인증 앱 연결 화면이 나와요. 모든 운영자 로그인이 끊기고, 이 일은 기록에 "인증 앱 다시 연결"로 남지 않으니 직접 메모해 두세요.

```sql
update admins set totp_on = false, totp_on_at = null, totp_secret = null, totp_last_step = 0,
  backup_hashes = '[]', session_version = session_version + 1;
```
