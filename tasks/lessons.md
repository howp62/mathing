# Lessons

## 2026-11-25 · 디자인을 바꿀 때 기존 움직임과 실제 카드 너비도 유지하기

- **무슨 일이 있었나**: 종이 노트형으로 바꾸며 기존 첫 화면의 선 그리기·점 움직임을 제거했다. 사용자는 예시 그림의 모션 누락과 행렬 타일의 가로 넘침도 지적했다. 이전에는 그림 원본·문구 보존만 검사해 모션 여부와 긴 수식의 너비 영향을 놓쳤다.
- **규칙**: 기능·문구를 유지하는 디자인 변경에는 기존 움직임과 동작 줄이기 설정도 포함한다. 그림은 개수가 아니라 실제 모션 대상이 있는지 전부 확인한다. 휴대폰에서는 가장 긴 수식을 가진 카드로 배경 안에 머무는지 본다. 가로 넘침은 본문을 숨겨 가리지 말고 목록의 최소 너비와 수식 줄바꿈부터 고친다. 실제 브라우저에서 못 본 배치·모션은 확인했다고 쓰지 않는다.

## 2026-11-25 · 생활 장면부터 말하고, 고른 질문을 보며 쓰게 하기

- **무슨 일이 있었나**: 동료 교사가 예시 제목의 수학 용어와 어색한 표현 때문에 처음 쓰는 학생이 읽기 어렵다고 알려 줬다. 생각 열기에서 보던 질문도 글쓰기에서는 접힌 도움말에 숨어 있어 참고하기 어려웠고, 가입 오류가 나면 별명과 동의까지 초기화됐다.
- **규칙**: 학생용 제목은 생활 속 장면이나 궁금증부터 쓰고, 수학 용어는 본문에서 관계를 설명할 때 쓴다. 쉬운 표현으로 바꾸면서 수학적 가정과 범위를 지우거나 실제 효과를 과장하지 않는다. 앞 화면에서 고른 질문은 다음 화면에서 펼쳐 두고, 스크롤·작성 방식 변경·질문 변경 후에도 문맥과 쓰던 글을 유지한다. 가입 오류 때는 서버 검증을 유지하면서 비밀이 아닌 입력은 남기고 비밀번호만 비운다. 실제 화면을 열지 못했다면 휴대폰 확인을 마쳤다고 쓰지 않는다.

## 2026-11-13 · 이름은 표기 방식까지 함께 제안하기

- **무슨 일이 있었나**: 서비스 이름 'mathing'을 추천하면서 화면 표기를 한글 '매싱'으로 정했다. 목업을 본 사용자가 한글로 쓰면 뜻이 더 안 와닿는다며 영문 'mathing'으로 바꿨다.
- **규칙**: 외래어나 말장난이 섞인 이름을 제안할 때는 화면에 어떻게 쓸지(한글 음차 / 원어 / 함께 표기)도 선택지로 같이 묻는다. 말장난의 뜻은 원어 철자에서 드러나는 경우가 많으니, 음차를 기본값으로 정하지 않는다.

## 2026-11-13 · 실제 데이터베이스 드라이버로도 점검하기

- **무슨 일이 있었나**: 연습용 데이터베이스(PGlite)로만 수업 흐름을 점검하고 끝냈다. Supabase(postgres.js)로 바꾸자 `$3::jsonb` 자리에 넣은 JSON 문자열이 한 번 더 감싸져 '문자열 하나'로 저장됐고, 교사 수업 화면이 `ids.map is not a function`으로 멈췄다.
- **규칙**: 드라이버나 데이터베이스를 바꾸면, 쓰기가 있는 흐름(입장·제출·띄우기·평가)을 바뀐 쪽에서 한 번 더 끝까지 돌린다. JSON을 문자열로 넘길 때는 `$n::text::jsonb`로 써서 어느 드라이버든 Postgres가 한 번만 해석하게 한다.
