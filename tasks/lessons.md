# Lessons

## 2026-11-13 · 이름은 표기 방식까지 함께 제안하기

- **무슨 일이 있었나**: 서비스 이름 'mathing'을 추천하면서 화면 표기를 한글 '매싱'으로 정했다. 목업을 본 사용자가 한글로 쓰면 뜻이 더 안 와닿는다며 영문 'mathing'으로 바꿨다.
- **규칙**: 외래어나 말장난이 섞인 이름을 제안할 때는 화면에 어떻게 쓸지(한글 음차 / 원어 / 함께 표기)도 선택지로 같이 묻는다. 말장난의 뜻은 원어 철자에서 드러나는 경우가 많으니, 음차를 기본값으로 정하지 않는다.

## 2026-11-13 · 실제 데이터베이스 드라이버로도 점검하기

- **무슨 일이 있었나**: 연습용 데이터베이스(PGlite)로만 수업 흐름을 점검하고 끝냈다. Supabase(postgres.js)로 바꾸자 `$3::jsonb` 자리에 넣은 JSON 문자열이 한 번 더 감싸져 '문자열 하나'로 저장됐고, 교사 수업 화면이 `ids.map is not a function`으로 멈췄다.
- **규칙**: 드라이버나 데이터베이스를 바꾸면, 쓰기가 있는 흐름(입장·제출·띄우기·평가)을 바뀐 쪽에서 한 번 더 끝까지 돌린다. JSON을 문자열로 넘길 때는 `$n::text::jsonb`로 써서 어느 드라이버든 Postgres가 한 번만 해석하게 한다.
