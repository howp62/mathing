## 결과

- 추천 규칙 9가지 경우 통과(`node lib/recommend.ts`). 타입 검사 통과.
- 색 대비: 새 본문 글자 모두 4.5:1 이상. 기존 오류 글자색(`--danger`)이 4.29:1이라 #A8392F로 진하게(5.09:1).
- 글꼴: 고운바탕이 `/_next/static/media`에서만 오고 바깥 요청 0개, CSP 오류 없음.
- 실제 DB 시험 계정(점검디자인): 첫 추천 "다항식" → 목록에서 "방정식과 부등식"을 골라 7단계(단계 표시 글자 1/7~7/7 확인, 공유 끔) → 다음 추천 "경우의 수". 내 노트 지도 새 색. 계정 삭제 후 사용자 0명.
- 휴대폰 360×740, 375×667: 첫 화면이 스크롤 없이 한 화면(짧은 화면은 그림이 줄어듦), 홈·단계 표시 가로 넘침 없음.
- 예시 카드 그림 색은 색 값만 바꿈(색을 빼면 이전과 같음을 확인) → 검수 상태 그대로.
- 함께 고침: 오류 화면(`app/error.tsx`)이 처음부터 없던 CSS 이름을 써서 꾸밈 없이 보이던 것.
- dorms-check 코드 점검: 위험 0, 권고는 이전과 같음.
- 못 한 것: 고친 오류 화면은 일부러 오류를 낼 방법이 없어 화면으로는 못 봄(쓰는 CSS 이름이 모두 있는지만 확인).
