2026-11-14 결정: B의 첫 화면 + C의 색·글꼴. 홈은 다음 단원 추천 칸 + 단원 목록, 단원 활동에 단계 표시. (PRD 1.2)

DoRm Edu 영상 「함흥hero와 평양UI로 남들과 다른 UI 만들기」(58분)의 생각을 mathing에 맞게 옮겼어요. 세 시안 모두 같은 세 화면(첫 화면 · 단원 고르기 · 쓰기 단계)으로 보여 드려요.

① 평양 UI (37:08~)모양은 담백하게 통일하고, 다른 곳에 쓸 때는 색·글꼴만 바꿔 변주한다 (shadcn/ui + tweakcn).
② 함흥 히어로 (2:17, 52:07)첫 화면(히어로)만 이목을 끌게: 큰 두 줄 제목, 누르고 싶은 CTA 하나, 움직이는 배경.
③ 글꼴·벤토 그리드 (1:16, 24:38)한글은 글꼴이 품질을 좌우한다. 기록은 크기가 다른 칸(벤토)에 묶는다.
④ 강조는 따로, 풀와이드 (49:10, 53:43)강조할 부분만 따로 한 카드로 묶고, 히어로는 여백 없이 꽉 채운다.
세 시안 공통 제안: 단계 표시(브레드크럼, 6:43) — 영상에서 "단계가 많으면 학생이 지금 어디 있는지 헷갈린다"고 한 부분이에요. 지금 단원 활동은 7단계(관련성 → 도입 → 관심사 → 예시 → 생각 열기 → 쓰기 → 저장)인데 이름 없는 막대만 있어요. 세 번째 화면처럼 지나온 단계 · 지금 단계 · 다음 단계를 글자로 보여 주는 걸 어떤 시안을 고르든 함께 넣기를 권해요.
A

담백한 기본 + 색 변주

영상 ① 평양 UI · tweakcn 'Supabase' 테마처럼

화면 구조는 지금 그대로 두고 색·둥글기·그림자만 바꿔요. 베이지 종이 느낌 대신 흰 바탕에 초록 하나만 쓰는 깔끔한 테마예요. 영상 강사가 "특별히 힘을 줄 게 아니면 Supabase 테마가 제일 깔끔하다"고 한 방향이에요.

바뀌는 것
  • 색 · 둥글기 · 그림자 (CSS 색 변수만)
  • 첫 화면 제목을 크게, 설명은 번호 목록으로
  • 공통: 쓰기 단계에 단계 이름 표시
좋은 점
  • 가장 작은 변경, 화면 구조·기능은 그대로
  • 깔끔하고 단정해서 어느 화면이든 통일돼 보임
주의할 점
  • 지금의 따뜻한 종이 느낌이 사라져 조금 '앱스럽게' 차가워질 수 있음
  • PRD의 분위기 '차분하고 따뜻하게' 중 '따뜻하게'가 약해짐
작업 크기작음 — 색 변수 교체 + 첫 화면 1개 + 단계 표시
B

함흥 히어로 + 평양 본문

영상 ② 히어로 · ④ 풀와이드 · 타이포그래피

주소를 처음 연 학생이 보는 첫 화면만 강하게 바꿔요. 화면을 꽉 채운 어두운 배경 위에 관심사(주황 점)와 수학 개념(초록 점)이 선으로 이어지는 움직임, 크고 두꺼운 두 줄 제목, 누르고 싶은 CTA 하나. 로그인한 뒤의 화면은 지금의 차분한 디자인을 그대로 써요.

바뀌는 것
  • 첫 화면(로그인 전)만: 풀와이드 어두운 히어로, 연결이 그려지는 움직임, 큰 두 줄 제목, CTA 하나
  • 안쪽 화면은 그대로 + 공통 단계 표시
좋은 점
  • 처음 주소를 연 학생에게 '이건 뭔가 다르다'는 인상
  • '연결'이라는 뜻이 그림으로 바로 보임
  • 매일 쓰는 안쪽 화면은 차분함 유지
주의할 점
  • 첫 화면과 안쪽 분위기가 달라 이어지는 느낌이 약할 수 있음
  • 움직임은 휴대폰의 '동작 줄이기' 설정이면 멈추게 함
  • 영상 대신 SVG로 그려서 데이터는 거의 안 씀
작업 크기중간 — 첫 화면 1개 새로 + 단계 표시
C

벤토 노트

영상 ③ 벤토 그리드 · 글꼴 · ④ 강조는 따로

'내 연결 노트'라는 이름에 맞춰 줄 공책과 만년필 잉크(남색), 형광펜(노랑) 느낌으로 바꾸고, 제목은 명조 계열 글꼴(고운바탕, 무료 상업용 OFL)을 써요. 홈은 벤토 그리드로: "지금 시작할 단원"을 큰 칸 하나로 강조하고, 내 연결 · 친구들의 연결 · 단원 목록을 작은 칸에 묶어요.

바뀌는 것
  • 색(남색 잉크 · 노란 형광펜 · 종이), 제목 글꼴 고운바탕
  • 홈을 벤토 그리드로: 큰 '다음 단원' 칸 + 내 연결 · 친구들 연결 칸
  • 첫 화면에 예시 연결 카드 미리보기, 쓰기 칸은 줄 공책
좋은 점
  • '노트'라는 콘셉트와 가장 잘 맞고 따뜻함 유지
  • 다음에 할 일이 한눈에 보임
  • 첫 화면에서 무엇을 쓰는지 바로 보여 줌
주의할 점
  • 변경이 가장 큼: 홈 구조와 새 숫자(친구들 새 글 수 등) 조회 필요
  • 글꼴 파일이 더해져 첫 로딩이 조금 늘어남
  • "다음에 배울 단원"은 학생이 고른 게 아니라 순서대로 추천
작업 크기큼 — 색 · 글꼴 + 홈 다시 만들기 + 첫 화면 + 단계 표시

섞어서 골라도 돼요

  • B의 첫 화면 + C의 색·글꼴: 첫인상은 강하게, 안쪽은 노트 느낌
  • A의 색 + B의 첫 화면: 전체는 깔끔하게, 첫 화면만 힘주기
  • 지금 디자인 + 단계 표시만: 가장 작은 변화

영상에서 쓴 shadcn/ui · Tailwind · 21st.dev는 React+Tailwind 프로젝트용이에요. mathing은 이미 색을 CSS 변수로 관리하고 있어서, 프레임워크를 바꾸지 않고 같은 생각(테마 변주 · 히어로)만 가져올 수 있어요. 시안의 그림과 코드는 직접 만든 것이고, 글꼴은 Pretendard·고운바탕 모두 무료 상업용(OFL)이에요.
