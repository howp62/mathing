## 1. 한 줄 요약

고등학생이 **단원을 시작하기 전에 스스로** 열어서 그 단원과 자기 관심사·진로의 연결을 직접 글로 써 보고, 전국의 다른 학생들이 쓴 연결을 이름 없이 둘러보는 웹사이트.

로그인 전 첫 화면은 사용자가 고른 종이 노트형으로 구성한다. 크림색 바탕, 벽돌색 시작 버튼, 줄노트 모양 연결 그림 카드로 안내하며 기존 문구와 가입·로그인·처리방침 기능은 유지한다. 참고 자료와 적용 범위는 `docs/FIRST-SCREEN-DESIGN.md`에 기록한다.

## 2. 배경과 문제

- 고등학교에 올라와 난이도가 오르면서 많은 학생이 수학에 흥미를 잃는다.
- 수학은 일상·진로와 이어진 곳이 많지만, 학생은 그 연결을 직접 느끼지 못한다.
- 배운 내용과 자기 삶의 연결을 **스스로 쓰게 하면** 흥미와 성적이 함께 오르고, 성공 기대가 낮던 학생에게 효과가 가장 크다(Hulleman & Harackiewicz, 2009). 연결을 "보여주는 것"보다 "만들게 하는 것"이 핵심이다.
- mathing은 학생이 단원을 시작할 때마다 혼자 5~10분 써 보게 해서, 교사의 수업 시간이나 운영 없이 이 효과를 얻는 것을 노린다.

## 3. 목표와 비목표

### 목표

1. 학생이 단원과 자기 진로·일상의 연결을 **자기 말로 설명**해 보게 한다.
2. 다른 학생들의 연결을 보며 "수학이 이런 데도 쓰이네"를 넓게 경험하게 한다.
3. 학생이 쓰기 전·후 관련성 변화를 스스로 확인하며 동기를 얻게 한다.
4. 교사의 준비나 운영 없이 돌아간다. 운영자는 신고 처리만 한다.

### 비목표

- 문제 풀이, 채점, 진단.
- 점수, 배지, 레벨, 순위, 공감 수 표시, 댓글.
- 교사용 기능: 반·수업 관리, 전자칠판, 학생 글 평가, 엑셀 내보내기.
- AI 코치.
- 모둠·반 단위 공유, 사용 통계, 인터넷 없이 쓰기. → 14장 "나중에"
- 이름·학교·학번·이메일 수집.

## 4. 사용자

| 사용자 | 설명 | 원하는 것 |
|---|---|---|
| **학생: 진로가 있는 학생** | 희망 직업·학과가 있음 | 내 진로와 이 단원이 어떻게 이어지는지 |
| **학생: 진로 미정 학생** | 고1에 많음 | 진로가 없어도 관심사로 참여하기 |
| **학생: 자신감이 낮은 학생** | "나는 해도 안 돼" | 틀릴 걱정, 평가받을 걱정 없이 쓰기. 이름 없이 공유하기 |
| **운영자** (선생님 본인) | 사이트 하나를 운영 | 부적절한 글을 빨리 숨기기, 좋은 연결을 추천하기 |
| **주소를 알려 주는 교사** | 동료 수학교사 | 학생에게 주소만 알려 주면 끝. 설치·관리 없음 |

대상 과목: 고1 공통수학1·2, 고2 대수·미적분I·확률과 통계(16개 대단원).

## 5. 핵심 사용 흐름: 단원 하나

| 순서 | 화면 | 학생이 하는 일 |
|---|---|---|
| 0 | 가입·로그인 | 처음이면 별명 + 비밀번호로 가입, 만 14세 이상 체크, 처리방침 동의, 복구 코드 저장. 다음부터는 로그인 상태 유지 |
| 1 | 단원 고르기 | 과목별 16개 단원 중 지금 시작하는 단원을 고름. 이미 쓴 단원은 표시, 준비 중 단원은 잠김 |
| 2 | 관련성(전) | "이 단원이 나와 관련 있다고 느낀다" 5점 |
| 3 | 도입 | "이 단원은 어디서 나올까?" 카드 2~3장을 위아래로 내려 봄 |
| 4 | 관심사 확인 | 처음이면 관심사·진로 고르기, 다음부터는 "이대로 갈까?" |
| 5 | 예시 카드 | 내 관심사와 가까운 카드 2~3장 |
| 6 | 생각 열기 | 내 관심사 맞춤 질문(최대 3장) 다음 공통 질문 카드 4장을 하나씩 |
| 7 | 쓰기 | 3단계(장면 → 계산·비교·예측 → 닮은 개념, 개념 버튼) 또는 한 칸 자유 쓰기. 막히면 문장 틀과 예시·질문 다시 보기 |
| 8 | 저장 | 미리보기, 공유 켜짐/꺼짐, 관련성(후) 5점. 욕설·개인정보는 저장 전 걸러냄 |
| 9 | 친구들의 연결 | 같은 단원의 공유된 글을 이름 없이. 추천 연결 → 내 관심사 → 최신순. 공감·신고 |
| 10 | 내 연결 노트 | 지금까지 쓴 연결, 연결 지도, 관련성 전·후 변화, 다시 쓰기 |

한 단원에 5~10분이 목표다. 단원을 다 배운 뒤 노트에서 "다시 써 보기"를 권한다.

## 6. 기능 요구사항

우선순위: **P0** = 첫 공개에 꼭 필요, **P1** = 첫 공개에 넣되 미룰 수 있음, **P2** = 그 뒤.

### 6.1 계정

| ID | 기능 | 설명 | 우선 |
|---|---|---|---|
| A1 | 가입 | 별명(2~12자, 사이트 전체에서 하나뿐) + 비밀번호(영문·숫자 섞어 8자 이상). 별명에 실명·학교 이름을 쓰지 말라는 안내. 별명에도 자동 걸러내기 적용. 서버에서 가입 오류가 돌아오면 별명·나이 확인·처리방침 동의는 입력한 상태로 유지하고 비밀번호만 비운다. 동의하지 않은 항목을 임의로 체크하거나 가입 정보를 기기에 보관하지 않는다 | P0 |
| A2 | 가입 동의 | "만 14세 이상이에요" 체크 + 개인정보 처리방침 동의(링크) | P0 |
| A3 | 복구 코드 | 가입 직후 한 번만 보여 주는 코드. "캡처해 두세요". 코드 + 별명으로 비밀번호를 다시 정하고, 정하면 새 코드를 준다 | P0 |
| A4 | 로그인 | 별명 + 비밀번호. 5번 틀리면 10분 잠금. 로그인 유지 30일 | P0 |
| A5 | 로그아웃 | 어느 화면에서든. 같이 쓰는 기기를 위해 눈에 잘 띄게 | P0 |
| A6 | 비밀번호 바꾸기 | 바꾸면 다른 기기의 로그인은 모두 끊긴다 | P1 |
| A7 | 계정 지우기 | 계정과 모든 글·공감·신고를 한 번에 지운다. 별명을 다시 입력해 확인 | P0 |

### 6.2 단원과 프로필

| ID | 기능 | 설명 | 우선 |
|---|---|---|---|
| B1 | 단원 목록 | 과목별 16개 대단원. 내용이 있는 단원만 열리고 나머지는 "준비 중". 내가 쓴 단원에 표시 | P0 |
| B2 | 관심사·진로 | 관심사 태그 15개 중 여러 개 + 직접 입력, 진로 자유 입력(선택), "아직 몰라요". 계정에 기억하고 단원마다 바꿀 수 있다 | P0 |

| ID | 기능 | 설명 | 우선 |
|---|---|---|---|
| C1 | 관련성(전) | 단원을 고른 직후 5점 척도 한 문항. 건너뛸 수 있다 | P0 |
| C2 | 도입 카드 | 그 단원의 대표 예시 2~3장. 예시 카드는 어느 화면에서든 세로로 쌓는다(옆으로 넘기지 않음) | P0 |

| C5 | 3단계 쓰기 | ① 어떤 장면? ② 무엇을 계산·비교·예측? ③ 어떤 개념과 닮았나? 각 한두 문장, 최소 글자 수 없음 | P0 |
| C6 | 개념 고르기 | 3단계에서 단원의 개념 이름을 버튼으로 고른다 | P0 |
| C7 | 자유 쓰기 | 한 칸에 자유롭게 쓰는 방식으로 바꿀 수 있다 | P1 |
| C8 | 쓰던 글 임시 보관 | 저장 전 글·작성 방식·개념과 공유 여부·대표 관심사·관련성 전후 점수·보던 질문을 기기에 잠시 보관해 새로고침해도 유지한다(진행 단계는 처음부터). 질문은 문장으로 기억해 순서가 바뀌어도 다시 찾고, 현재 질문에 없으면 첫 질문을 보여 준다. 질문 정보가 없는 기존 형식의 임시 글도 읽는다. 단원·처음 쓰기/다시 쓰기·계정마다 분리하고 로그아웃하면 지운다 | P0 |
| C9 | 자동 걸러내기 | 저장 전 욕설·비하 표현, 전화번호·이메일·인터넷 주소·SNS 아이디 모양을 찾아 저장을 막고 이유를 알려 준다 | P0 |
| C10 | 저장 | 미리보기, "다른 학생들에게 이름 없이 공유"(기본 켜짐, "모두가 볼 수 있어요" 안내), 관련성(후) 5점 | P0 |
| C11 | 다시 쓴 연결 | 저장한 단원마다 "처음 연결"을 남기고 "다시 쓴 연결" 하나를 더 쓸 수 있다. 갤러리에는 다시 쓴 것이 보이고, 받은 공감은 유지, 추천 ★는 풀린다. 저장 화면에서 바꾼 대표 관심사도 저장되며, 노트와 갤러리에 쓰는 연결 글의 공통 태그가 바뀐다(처음 글의 본문은 유지). 예전 대표 관심사를 현재 프로필에서 지웠다면 현재 첫 관심사를 미리보기부터 표시해 저장 결과와 맞춘다 | P0 |
| C12 | 단계 표시 | 처음 쓰기 흐름 위에 "지난 단계 › 지금 단계 › 다음 단계"와 "n/7"을 글자로 보여 준다(막대와 함께) | P1 |
| C13 | 이전 버튼 | 단계마다 아래쪽에 "‹ 이전"과 돌아갈 단계 이름. 쓰던 글은 그대로 남는다 | P0 |
| C14 | 다시 보기 | 쓰기 화면 안에서 "예시와 다른 질문 더 보기"를 펼치면 내 관심사 예시 카드와 다른 생각 열기 질문이 보인다(다시 쓰기에서도). 지금 쓰는 질문은 펼침 영역 밖에 따로 보인다 | P1 |
| C15 | 문장 틀 | 칸마다 "이렇게 시작해 봐" 틀 2~3개. 누르면 칸 끝에 붙고 첫 빈칸 (   )이 선택돼 바로 채운다. 빈칸이 남으면 "다 썼어"에서 알려 준다 | P1 |
| C16 | 질문을 보며 쓰기 | 쓰기 화면 상단에 현재 질문 전문을 항상 펼쳐 보여 주고, 스크롤해도 상단에 남긴다. "질문 바꾸기"로 돌아가 다른 질문을 골라도 쓰던 글은 유지한다. 세 질문에 나눠 쓰기·한 칸 자유 쓰기·다시 쓰기 모두에서 제공한다 | P0 |

### 6.4 친구들의 연결 (갤러리)

| ID | 기능 | 설명 | 우선 |
|---|---|---|---|
| D1 | 열람 조건 | 그 단원에 내 연결을 저장한 뒤에만 열린다 | P0 |
| D2 | 익명 표시 | 별명은 보이지 않는다. 관심사 태그와 글만. 학생이 직접 쓴 관심사는 다른 학생에게 "기타"로 보인다. "내 관심사" 표시와 순서도 기본 관심사끼리만 견준다(직접 쓴 관심사가 같은지 알려 주지 않음). 내 글에는 "내 글" 표시 | P0 |
| D3 | 순서 | 운영자 추천 연결 → 내 관심사와 같은 글 → 최신순 | P0 |
| D4 | 관심사로 거르기 | 관심사 태그를 눌러 그 관심사의 글만 | P1 |
| D5 | 공감 | "오, 연결된다!" 하나. 숫자는 보이지 않는다. 내 글이 공감을 받았는지는 나만 안다 | P0 |

| D7 | 불러오기 | 한 번에 20개씩, 더 보기 | P0 |

## 11. 성공 지표

사용 통계를 모으지 않으므로, 데이터베이스에 저장된 글에서 센 합계를 운영자 화면 '합계'(F6)에서 본다(개인을 알아볼 수 없는 합계만). 관련성 전·후는 두 번 다 답한 글끼리 비교하고, 운영자 처리 시간은 따로 기록하지 않아 '48시간 넘게 기다리는 신고 수'로 대신 본다. 목표치는 첫 가설이며 써 보면서 조정한다.

| 지표 | 측정 | 첫 목표 |
|---|---|---|
| 핵심: 자기 말로 연결 | 저장된 연결 글 수, 다시 쓴 연결 비율 | 다시 쓴 비율 20% 이상 |
| 보조: 관련성 체감 | 관련성 전·후 평균 차이 | 후가 전보다 높음 |
| 공유 | 공유 켜진 글 비율 | 60% 이상 |
| 이어 쓰기 | 두 단원 이상 쓴 학생 비율 | 40% 이상 |
| 안전 | 신고로 숨긴 글 비율, 운영자 처리 시간 | 2% 이하, 48시간 안 |
