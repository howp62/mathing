# 예시 카드 검수 목록 (공통수학1)

학생에게 보이기 전에 선생님이 확인할 곳이에요. 2026-11-13에 Claude가 4세트의 숫자 계산과 사실 설명을 한 번 다시 확인했고, **2026-11-14에 선생님이 4세트 모두 검수를 마쳤어요.** 카드 파일은 `content/sets/`에 있고, 검수를 마친 세트는 파일 안의 `"status"`가 `"reviewed"`예요. 배포된 사이트에서는 reviewed 세트만 학생에게 열려요. 쿠키·숙소·머핀·체력 기록·동물 수 카드의 숫자는 지어낸 예시이고, 본문에 "~라고 해 볼게요"처럼 가정이라고 밝혀 두었어요.

## 다항식 (`cm1-polynomial.json`)

목업에서 옮긴 8장이에요.
- QR 코드의 오류 정정이 다항식 나눗셈의 나머지를 쓴다는 설명이 고등학생 수준으로 지나치게 단순하지 않은지.
- 디스토션 이펙터의 `y = x − x³/3`이 실제로 쓰이는 형태의 예시로 적절한지.
- 공 높이 `h(t) = −5t² + 12t + 2`, `h(2) = 6`. 계산은 확인함.

## 방정식과 부등식 (`cm1-equations.json`)

- 소리를 높낮이별로 나누는 계산에 복소수가 쓰인다는 설명(크기와 시작 위치를 함께 담는다는 표현).
- 다이빙 식의 −5t²은 중력을 어림한 값.
- 약 농도 `C(t) = −t² + 6t`는 일부러 단순하게 만든 모델.
- 물고기 모델에서 '최대 지속 생산량'이라는 용어를 쓴 것.
- 복소수 카드의 개념 '복소수'를 학생이 고르는 개념 목록에 넣을지.

## 경우의 수 (`cm1-counting.json`)

- DNA 세 글자 묶음과 기본 아미노산 20가지라는 설명이 생명과학 교과서와 같은지.
- 새 연구자가 다리의 색 고리로 개체를 구별한다는 내용.
- 배송 경로 프로그램이 모든 순서를 다 따지지 않고 계산 요령을 쓴다는 문장.

## 행렬 (`cm1-matrices.json`)

- 사진 밝기를 0~255로 저장한다는 설명('보통'으로 표현함).
- 밤하늘 사진을 여러 장 겹쳐 평균 내는 방법.
- 직항표 행렬을 제곱하면 갈아타는 방법의 수가 나온다는 설명(출발 시각은 빼고 셈).
- 멸종 위기 동물 보호에 행렬 모델을 '쓰기도 한다'는 표현.
- 회전 변환과 3×3 행렬 같은 예가 교육과정 범위를 넘는지.

# 관심사 맞춤 생각 열기 질문 (검수 전)

리뷰어 피드백("관심사를 바꿔도 질문이 같다")으로 2026-11-18에 Claude가 초안을 썼어요. 단원마다 기본 관심사 15개에 하나씩, 모두 60개예요. 학생이 고른 관심사의 질문(최대 3개)이 생각 열기에서 공통 질문 4개보다 먼저 나와요. 직접 쓴 관심사에는 맞춤 질문이 없어요.

- 파일: `content/sets/` 각 세트의 `"interestPrompts"`. 검수 상태는 세트와 따로 `"interestPromptsStatus"`예요.
- 지금은 모두 `"draft"`라서 **배포된 사이트에서는 보이지 않아요**(내 컴퓨터에서만 보임). 선생님이 확인한 단원부터 `"reviewed"`로 바꾸면 학생에게 보여요.
- 초안 기준: 그 단원 개념 안의 수학만, 학생이 겪을 만한 장면, 답이 하나로 정해지지 않은 질문, 확인이 필요한 사실·숫자 주장 없이(숫자는 모두 "~라면" 가정).
- 볼 것: 수학 내용이 맞는지, 그 관심사 학생에게 자연스러운 장면인지, 너무 어렵거나 쉬운지, 말투.
