#### 1. 아이템이 닿는 범위는 어디까지일까?

- ID: `game-range` · 관심사: 게임 · 개념: 원의 방정식

게임 지도의 한 칸을 1 m로 보고 아이템 중심을 (0, 0)이라고 해 볼게. 중심에서 5 m 떨어진 경계는 원이야. 캐릭터 위치 (3, 4)는 3²+4²=25라서 경계 위에 있어.

**식:** x²+y²=25, (3,4)는 경계 위

**검산·가정:** 3²+4²=25. 반지름 양수이며 경계와 내부를 구분.

**그림:** 게임 장면 아이콘과 circle 도식. 중심 (0,0) / 반지름 5 m. 수학 대상이 draw/pop으로 한 번 나타나며 동작 줄이기에서는 완성 그림을 표시합니다.


#### 2. 노래 중간에 표시를 하나 넣는다면?

- [x] 수학·장면·말투·그림 교사 검수 완료

- ID: `music-marker` · 관심사: 음악 · 개념: 선분의 내분

편집 화면의 시작점을 0초, 끝점을 150초라고 해 볼게. 두 점 사이를 2:3으로 나누는 곳에 표시를 넣고 싶어. 시작에서 전체 길이의 2/5만큼 가면 되니 60초야.

**식:** 150×2/(2+3)=60초

**검산·가정:** 내분비 AP:PB=2:3, 60:90=2:3.

**그림:** 음악 장면 아이콘과 divide 도식. 0초 → 150초 / 2 : 3 → 60초. 수학 대상이 draw/pop으로 한 번 나타나며 동작 줄이기에서는 완성 그림을 표시합니다.


#### 3. 운동장 두 지점은 얼마나 떨어져 있을까?

- [x] 수학·장면·말투·그림 교사 검수 완료

- ID: `sports-distance` · 관심사: 스포츠 · 개념: 두 점 사이의 거리

운동장을 m 단위 좌표로 나타내고 두 지점을 (1, 2), (4, 6)이라고 해 볼게. 가로 차이는 3 m, 세로 차이는 4 m야. 두 지점을 곧게 잇는 거리는 √(3²+4²)=5 m야.

**식:** d=√((4−1)²+(6−2)²)=5 m

**검산·가정:** 피타고라스 9+16=25. 실제 이동 경로 길이와 구분.

**그림:** 스포츠 장면 아이콘과 distance 도식. 가로 3 m · 세로 4 m / 직선 거리 5 m. 수학 대상이 draw/pop으로 한 번 나타나며 동작 줄이기에서는 완성 그림을 표시합니다.


#### 4. 양쪽 소매의 무늬를 똑같이 놓으려면?

- [x] 수학·장면·말투·그림 교사 검수 완료

- ID: `fashion-mirror` · 관심사: 패션·뷰티 · 개념: 대칭이동

옷 도안의 세로 중심선을 y축으로 잡는다고 해 볼게. 한 무늬의 점이 (3, 2)에 있으면 반대편 점은 (−3, 2)에 놓아. 좌우 위치만 바꾸고 높이는 그대로 두는 대칭이동이야.

**식:** (x,y) → (−x,y)

**검산·가정:** y축 대칭은 x 부호만 바뀜. 좌표 단위는 도안 한 칸.

**그림:** 패션·뷰티 장면 아이콘과 mirror 도식. 옷의 중심선 y축 / (3,2) → (−3,2). 수학 대상이 draw/pop으로 한 번 나타나며 동작 줄이기에서는 완성 그림을 표시합니다.


#### 5. 둥근 케이크 위에 장식을 놓는다면?

- [x] 수학·장면·말투·그림 교사 검수 완료

- ID: `cooking-circle` · 관심사: 요리 · 개념: 원의 방정식

케이크 윗면의 중심을 cm 단위로 (2, 3), 반지름을 4라고 해 볼게. 테두리의 점들은 중심까지 거리가 모두 4 cm야. (6, 3)에 놓은 장식은 원의 식에 맞으니 테두리 위에 있어.

**식:** (x−2)²+(y−3)²=16

**검산·가정:** (6−2)²+(3−3)²=16.

**그림:** 요리 장면 아이콘과 circle 도식. 중심 (2,3) / 반지름 4 cm. 수학 대상이 draw/pop으로 한 번 나타나며 동작 줄이기에서는 완성 그림을 표시합니다.


#### 6. 자막을 오른쪽 위로 옮기려면?

- [x] 수학·장면·말투·그림 교사 검수 완료

- ID: `video-shift` · 관심사: 영상·SNS · 개념: 평행이동

영상 도안에서 오른쪽을 x의 양의 방향, 위쪽을 y의 양의 방향으로 정해 볼게. 자막의 한 점 (2, 1)을 오른쪽 3칸, 위로 2칸 옮기면 (5, 3)이야. 모든 점을 똑같이 옮기면 자막 모양은 유지돼.

**식:** (x,y) → (x+3,y+2)

**검산·가정:** 단순 좌표계의 위쪽을 +y로 명시. 화면 픽셀 좌표와 혼동하지 않음.

**그림:** 영상·SNS 장면 아이콘과 shift 도식. 오른쪽 3 · 위로 2 / (2,1) → (5,3). 수학 대상이 draw/pop으로 한 번 나타나며 동작 줄이기에서는 완성 그림을 표시합니다.


#### 7. 두 선이 직각으로 만나게 하려면?

- [x] 수학·장면·말투·그림 교사 검수 완료

- ID: `design-perpendicular` · 관심사: 그림·디자인 · 개념: 직선의 평행과 수직

포스터에서 한 선을 y=2x+1로 그린다고 해 볼게. 다른 선의 기울기를 −1/2로 정하면 두 기울기의 곱은 −1이야. 두 직선이 만나면 직각이 돼.

**식:** 2×(−1/2)=−1

**검산·가정:** 유한 기울기 두 직선의 수직 조건. 그림은 개념도.

**그림:** 그림·디자인 장면 아이콘과 parallel 도식. 기울기 2 · −1/2 / 기울기의 곱 −1. 수학 대상이 draw/pop으로 한 번 나타나며 동작 줄이기에서는 완성 그림을 표시합니다.


#### 8. 강아지 놀이터에서 벽까지 거리는?

- [x] 수학·장면·말투·그림 교사 검수 완료

- ID: `animal-boundary` · 관심사: 동물 · 개념: 점과 직선 사이의 거리

놀이터 지도를 m 단위로 그리고 벽을 직선 x=2로 나타내 볼게. 강아지가 (7, 4)에 있다면 벽과 가장 가까운 점은 (2, 4)야. 두 점을 수직으로 이은 거리는 5 m야.

**식:** d=|7−2|=5 m

**검산·가정:** 일반식 |x−2|/√1. 직선 전체로 본 가정.

**그림:** 동물 장면 아이콘과 wall 도식. 벽 x=2 / 수직 거리 5 m. 수학 대상이 draw/pop으로 한 번 나타나며 동작 줄이기에서는 완성 그림을 표시합니다.


#### 9. 두 여행 지점 사이에서 어디서 만날까?

- [x] 수학·장면·말투·그림 교사 검수 완료

- ID: `travel-meet` · 관심사: 여행 · 개념: 선분의 내분

지도에서 A(0, 0)와 B(8, 4)를 잇는 곧은 길이 있다고 해 볼게. A에서 B 쪽으로 1:3으로 나뉘는 곳을 고르면 전체의 1/4 지점이야. 그 점의 좌표는 (2, 1)이 돼.

**식:** P=((3×0+1×8)/4,(3×0+1×4)/4)=(2,1)

**검산·가정:** AP:PB=1:3. 실제 도로가 아닌 곧은 길 모형.

**그림:** 여행 장면 아이콘과 quarter 도식. A(0,0) → B(8,4) / 1 : 3 → P(2,1). 수학 대상이 draw/pop으로 한 번 나타나며 동작 줄이기에서는 완성 그림을 표시합니다.


#### 10. 길이 둥근 구역에 살짝 닿을까?

- [x] 수학·장면·말투·그림 교사 검수 완료

- ID: `car-tangent` · 관심사: 자동차 · 개념: 원과 직선의 위치 관계

지도에서 보호 구역을 중심 (0, 0), 반지름 3인 원으로 정해 볼게. 도로를 직선 y=3으로 보면 중심에서 도로까지 거리가 반지름과 같아. 그래서 직선은 원과 한 점 (0, 3)에서만 만나.

**식:** x²+y²=9, y=3 → x²=0

**검산·가정:** 대입 시 x=0 중근. 도로 폭을 무시한 모형.

**그림:** 자동차 장면 아이콘과 tangent 도식. 중심과 길의 거리 3 / 만나는 점 1개. 수학 대상이 draw/pop으로 한 번 나타나며 동작 줄이기에서는 완성 그림을 표시합니다.


#### 11. 걷기 기록의 점들을 옮겨 그린다면?

- [x] 수학·장면·말투·그림 교사 검수 완료

- ID: `health-path` · 관심사: 건강·의학 · 개념: 평행이동

실내 걷기 경로를 좌표로 그려 시작점이 (4, 2)였다고 해 볼게. 경로 전체를 왼쪽 4칸, 아래로 2칸 옮기면 시작점은 (0, 0)이야. 각 구간 길이는 그대로라 모양을 비교하기 편해.

**식:** (x,y) → (x−4,y−2)

**검산·가정:** 동일 벡터 평행이동은 거리 보존. 건강 효과 주장 없음.

**그림:** 건강·의학 장면 아이콘과 leftdown 도식. 왼쪽 4 · 아래로 2 / 시작점 (4,2) → (0,0). 수학 대상이 draw/pop으로 한 번 나타나며 동작 줄이기에서는 완성 그림을 표시합니다.

**식:** A⊆U

**그림:** 영상·SNS 장면 아이콘과 counter 도식. 모든 짧은 영상? / 20초 · 10회인 반례. 수학 대상이 draw/pop으로 한 번 나타나며 동작 줄이기에서는 완성 그림을 표시합니다.


#### 7. 두 색을 모두 쓰지 않는 디자인은?

- [x] 수학·장면·말투·그림 교사 검수 완료

- ID: `design-de-morgan` · 관심사: 그림·디자인 · 개념: 집합의 연산

도안 네 개 중 파랑을 쓴 도안을 A, 빨강을 쓴 도안을 B라고 해 볼게. 두 색 중 어느 것도 쓰지 않은 도안은 A∪B 바깥에 있어. 이는 파랑도 없고 빨강도 없는 도안을 함께 고르는 것과 같아.

**식:** (A∪B)ᶜ=Aᶜ∩Bᶜ

**검산·가정:** 전체집합은 도안 네 개, 여집합 기준 고정.

**그림:** 게임 장면 아이콘과 compose 도식. 먼저 +2 · 다음 ×3 / x=4 → 6 → 18. 수학 대상이 draw/pop으로 한 번 나타나며 동작 줄이기에서는 완성 그림을 표시합니다.
