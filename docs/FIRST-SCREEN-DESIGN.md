# 첫 화면 디자인 비교 · 2026-11-25

## 범위

로그인 전 `/` 첫 화면의 비교 시안이다. 현재 `app/page.tsx`의 모든 기본 문구, 로고, 관심사·수학 개념 이름과 연결 관계, 가입·로그인·처리방침 연결을 유지한다. 앱 코드와 `AGENTS.md`·`CLAUDE.md`는 선택 전까지 수정하지 않는다. 시안의 링크는 기존 운영 사이트의 같은 목적지로 연결한다.

비교 시안: `mockup/first-screen-comparison.html`. 대화 안에서 세 안을 나란히 보여 주며, 좁은 화면에서는 글자가 작아지지 않도록 세로로 배치한다. 시안 밖의 '고르기' 버튼은 디자인 선택을 위한 것으로 앱의 신규 기능이 아니다.

## 직접 열어 확인한 자료

getdesign.md는 각 브랜드의 공개 화면을 분석한 자료이며 브랜드 공식 가이드는 아니다. 이 프로젝트에는 브랜드 로고나 원본 제품 문구를 가져오지 않고, 색·여백·글자 위계·버튼·카드 구성만 참고한다.

두 사이트의 공개 페이지와 사용 예제를 웹 도구로 열어 확인했다. 21st.dev의 전체 컴포넌트 소스는 로그인 전 공개되지 않는 부분이 있어 설치하지 않고 직접 작성한 시안의 모양·배치에만 참고했다. CDN 미리보기 이미지는 내려받기 요청이 실패해 이미지 자체를 직접 봤다고 주장하지 않는다. 브라우저 조작 도구 역시 `The browser access host is unavailable`을 반환했다.

## 공통 디자인 규칙

- 첫 주요 행동은 기존 '가입하고 시작하기'를 벽돌색 채움으로 강조한다. 사용자 후속 요청에 따라 로그인도 동일 크기의 버튼으로 표시하고 종이색 바탕·벽돌색 테두리로 구별한다.
- 가입·로그인 버튼은 같은 너비·높이·글자 크기·여백·모서리를 공유하며 높이 54px 이상으로 둔다. 처리방침 연결은 누름 영역 44px 이상으로 둔다.
- 관심사는 따뜻한 색, 수학 개념은 푸른색으로 구분하되 기존 이름을 함께 표시한다. 그림은 선택할 수 있는 버튼처럼 동작하지 않는다.
- 본문은 15px 전후로 읽기 쉽게 두고, 대비를 확인한다. 긴 문구가 늘어나면 잘라 숨기지 않고 아래로 늘어난다.
- 기존 첫 화면의 연결선 그리기·점 움직임을 유지하고, '동작 줄이기' 설정에서는 완성된 그림을 정적으로 보여 준다. 마우스를 올려야만 보이는 설명은 넣지 않는다. 눌림·키보드 초점은 표시한다.
- 종이 노트형을 기본 추천한다. 기존 앱 본문의 종이색·남색·따뜻한 강조색과 이어져 학생이 첫 화면에서 활동 화면으로 이동할 때 차이가 작다. 시작 행동의 선명함을 더 중시하면 단정한 시작형을 고를 수 있다.

## 선택 뒤 적용·확인

선택한 안에 필요한 `app/page.tsx`의 배치와 `app/globals.css`의 `.landing` 전용 스타일만 수정한다. 로그인 후 화면, 서버 동작, 자료, 문구, 사용자 관점 규칙은 유지한다. 새로운 외부 패키지와 학생 브라우저의 외부 요청을 추가하지 않는다.

390px 실제 브라우저에서 첫 화면과 가입·로그인·처리방침 연결, 문구 잘림·가로 넘침·버튼 누름·키보드 초점을 확인한다. 브라우저가 연결되지 않으면 자동 검사와 실제 화면 확인을 구분해 미확인 범위를 알린다.

## 선택·적용 결과

2026-11-25 사용자가 종이 노트형을 선택했다. `app/page.tsx`에서 기존 설명 뒤에 줄노트 모양 그림 카드를 놓고 기존 행동들을 아래에 묶었다. `.landing` 전용 크림색·벽돌색·남색, 제목 글꼴 구분, 12px 모서리의 주 버튼을 적용했다. 새 글꼴·패키지·외부 요청은 추가하지 않았다. 높이가 작은 화면에서는 그림과 여백을 줄이고 본문은 잘라 숨기지 않는다.

실제 페이지의 서버 렌더링 결과를 수정 전과 대조해 기본 문구·링크·로고·그림의 9개 이름과 6개 연결·삭제 완료 안내·로그인 후 홈 이동을 확인했다. 첫 화면 스타일 영역 밖의 CSS가 같은 것도 확인했다. 타입 검사와 기존 TOTP·단원 추천 시험을 통과했고 핵심 색상 대비 5쌍은 모두 4.5:1 이상이다. 환경파일·학생 자료 없는 임시 소스 사본으로 개발 서버를 실행해 첫 화면 HTTP 200을 확인했다.

브라우저 조작 연결은 여전히 사용할 수 없어 **390px 실제 클릭·배치 검사는 미완료**다. 서버 응답이나 DOM 검사를 실제 화면 확인으로 간주하지 않는다. 커밋·푸시·배포하지 않았다.

### 움직임 보존 정정

종이 노트형 적용에서 첫 화면의 기존 움직임을 제거했던 것을 사용자가 지적해, 2026-11-25 연결선이 차례로 그려지고 점이 움직이는 동작을 복원했다. 색·배치·문구·그림 연결은 유지한다. 동작 줄이기에서는 애니메이션 없이 선과 점을 완성된 상태로 표시한다.

사용자 선택 후 15초 소개를 그림 칸에 추가했다. 한 도형이 관심사 카드·그래프를 거쳐 기존 연결 그림으로 이어진다. 가입·로그인을 막지 않으며 건너뛰기와 동작 줄이기를 지원한다. 출처·프레임 관찰·구성은 [INTRO-MOTION.md](./INTRO-MOTION.md)에 기록한다.
