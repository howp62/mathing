# 첫 화면 15초 소개 · 2026-11-25

사용자는 후보 1번을 선택하고 로그인 버튼을 가입 버튼과 같은 크기로 바꾸도록 요청했다. 기존 종이 노트형, 문구, 가입·로그인 목적지와 사용자 관점 규칙을 유지한다.

## 참고와 관찰

- 작품: [zero / @twoclipping — Code-based UI motion design showreel](https://jasonzhu.ai/en/prompts/claude-animation/2103273003555402193)
- [원 게시물](https://x.com/twoclipping/status/2103273003555402193)
- 프롬프트 발췌: “One shape, never cut”. 한 도형의 크기·모서리·내용을 바꾸며 장면을 이어가는 원리만 참고한다. 원작의 코드·음악·상표는 앱에 넣지 않는다.
- 공개 원본은 720×720, 약 14초. 임시 도구로 10fps(0.1초 간격), 0.0~13.9초의 PNG 140장을 추출했다. 20장씩 7개의 모음 이미지로 전부 열어 확인했다. 원본·추출 파일은 `/tmp/mathing-intro-reference/`에 있으며 저장소·배포물에 넣지 않는다.
- 다음 구간은 추출 화면에서 관찰한 값이며 장면 경계는 약 ±0.1초다. 위치는 화면의 왼쪽 위를 (0%, 0%), 오른쪽 아래를 (100%, 100%)로 본 대략값이다. 포인터 움직임·시점 확대와 실제 도형 이동을 구분한다. 음향은 분석하지 않았다.

| 시간 | 무엇이 | 어디서 어디로·어떻게 | 걸리는 시간 |
|---|---|---|---|
| 0.0~0.5초 | 포인터 | 오른쪽 아래 약 (85%, 80%) → 중앙 버튼 오른쪽 (61%, 58%) | 약 0.5초 |
| 0.5~1.2초 | 검은 가로 버튼 | 중앙을 유지하며 폭이 줄어 원이 됨. 내부 글자는 사라지고 회전 표시 뒤 체크가 나타남 | 약 0.7초 |
| 1.2~1.7초 | 중앙 원 | 좌우로 늘어나 알약 모양. 왼쪽 색 네모와 오른쪽 세로 막대가 나타남 | 약 0.5초 |
| 1.7~2.2초 | 알약 | 중앙을 유지하며 위아래로 커져 둥근 음악 카드가 됨. 왼쪽 위 네모·가로 진행선·재생 단추가 나타남 | 약 0.5초 |
| 2.2~2.9초 | 재생 표시·포인터 | 포인터가 카드 중앙의 재생 단추로 이동. 재생·정지 모양이 교체됨 | 약 0.7초 |
| 2.9~3.6초 | 진행선의 흰 점 | 카드 안 진행선 왼쪽 약 (28%, 59%) → 오른쪽 (73%, 59%) | 약 0.7초 |
| 3.6~4.0초 | 음악 카드 | 내부가 흐려지며 사라지고, 중앙 가로 막대로 높이가 줄어듦 | 약 0.4초 |

| 5.2~6.3초 | 가로 막대 | 폭이 줄어 스위치가 됨. 흰 원이 오른쪽 ↔ 왼쪽으로 여러 번 이동하며 바탕색도 바뀜 | 약 1.1초 |
| 6.3~7.3초 | 스위치 | 좌우로 늘어나 세 칸 선택 막대가 됨. 검은 선택 표시가 왼쪽 → 가운데 → 오른쪽으로 이동 | 약 1.0초 |

| 7.9~9.1초 | 그래프 위 점·숫자 상자 | 곡선의 왼쪽 아래 → 오른쪽 위를 따라 이동. 포인터도 이를 따라감 | 약 1.2초 |
| 9.1~9.6초 | 선택 표시·그래프 | 오른쪽 선택 표시가 가운데로 이동. 숫자가 줄고 곡선 모양이 바뀜 | 약 0.5초 |
| 9.6~10.4초 | 그래프 카드 | 내용이 흐려지고 가로 검색칸으로 줄었다가, 다시 아래로 펼쳐져 목록이 됨 | 약 0.8초 |
| 10.4~11.7초 | 검색 글자·목록 | 위 검색칸에 글자가 순서대로 나타남. 목록 줄이 줄어들고 선택 표시가 아래 줄로 이동 | 약 1.3초 |
| 11.7~12.2초 | 목록 | 위쪽 내용이 사라지고 마지막 줄 높이의 검은 알림 막대로 줄어듦. 왼쪽 체크 표시 등장 | 약 0.5초 |
| 12.2~13.0초 | 알림 막대 | 중앙을 유지하며 내용이 처음 버튼 글자로 바뀌고 폭이 조금 줄어듦 | 약 0.8초 |
| 13.0~13.9초 | 처음 버튼·포인터 | 버튼은 중앙에서 유지. 포인터가 오른쪽 아래로 물러남 | 약 0.9초 |

## 선택한 적용 방식

화면 전체를 가리는 방법 대신 기존 그림 칸 안에서 한 번 재생한다. 처음 할 일인 가입·로그인이 항상 보이고 바로 눌려야 하기 때문이다. 여러 장면을 별도 카드로 나열하는 방법보다 한 도형의 연속 변환을 살린다. 색은 종이색·벽돌색·남색을 유지한다.

| 소개 시간 | 앱에서 보여 줄 장면 |
|---|---|
| 0~2초 | 작은 벽돌색 점이 중앙에서 가로 카드로 커짐 |
| 2~5초 | 카드 안에 음악의 선·음표가 나타나고, 가로선이 다음 장면으로 이어짐 |
| 5~9초 | 카드가 그래프 판으로 커지고, 선이 왼쪽 아래에서 오른쪽 위로 그려짐 |
| 9~12초 | 한 선이 여러 연결선으로 이어지며 관심사·수학의 점과 이름이 나타남 |
| 12~15초 | 기존 연결 그림이 완성되고 소개 진행선이 끝남 |

- 실제 그림은 SVG와 CSS로 구현하며 영상 파일·외부 애니메이션 패키지를 넣지 않는다.
- 소개 중에는 남은 초·진행선·44px 이상 누름 영역의 ‘건너뛰기’를 보여 준다. 건너뛰면 즉시 완성 그림으로 전환하고 가입 버튼으로 키보드 초점을 옮긴다. 자동 종료는 초점을 옮기지 않는다.
- 제어 칸의 높이는 종료 뒤에도 유지해 가입·로그인 버튼이 갑자기 위로 움직이지 않게 한다. 남은 시간은 실제 경과 시간으로 계산하며, 배경 탭에서 돌아왔을 때 이미 15초가 지났다면 다음 갱신에 즉시 완료한다.
- 동작 줄이기를 켜면 대기 없이 완성된 그림을 보여 준다. 재생 중 설정을 바꾸면 즉시 끝낸다. 자바스크립트가 없어도 완성 그림과 가입·로그인 연결을 사용할 수 있다.
- 가입·로그인 버튼은 공통 규칙을 사용해 너비·높이·글자 크기·모서리·테두리 두께를 같게 한다. 가입은 벽돌색 채움, 로그인은 종이색 바탕과 테두리로 구별한다. 기존 ‘이미 계정이 있어요’는 로그인 위에 둔다.
- 390px 실제 브라우저 확인을 시도하고, 연결 불가이면 자동 검사와 직접 본 화면을 구분해 기록한다. 커밋·푸시·배포는 이번 요청에 포함되지 않는다.
